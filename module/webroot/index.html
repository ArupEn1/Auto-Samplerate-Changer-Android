The default. Try this first.

Use this if the phone speaker or other outputs go silent with the default. It fixed that on an LG V30.

Changes only the USB audio file and leaves the rest of the audio setup alone. Gentlest, but it did not stop resampling on the LG V30.

Help

Quick start

  1. Install the module and reboot. You have done this if you can read this page.
  2. Plug in your USB DAC and play a song in your music app.
  3. Turn on Auto-follow. Open the Auto tab and switch on Auto-follow track rate. It is off after installing, and nothing changes the sample rate until you turn it on. Leave Apply at boot on too.
  4. Check the badge at the top of the Status tab. Rate-matched (green) means the music is playing at its own sample rate.

For bit-perfect playback, use media volume at maximum and turn off EQ and effects in your music app.

If something is wrong

  • Nothing seems to happen: check that Auto-follow is on (Auto tab).
  • No sound, or the speaker is silent: Tools → Reset, then Audio → Mode → safest.
  • Badge says Resampled: make sure a song is playing through the DAC and Auto-follow is on, then try another mode on the Audio tab.
  • Still stuck: Tools → Save full report to Downloads while music plays, review the file, and attach it to a GitHub issue.
